三項深挖 / 可實驗的研究設計

以下均是本週研究啟發的延伸設計，不是原作者已在肺結節資料上證實的結果。所有方案以完整 3D CT、肺結節 GT 與 vessel mask 為共同輸入條件。

01 / RADIOlogy × vessel-aware detection

以「正常血管」當負提示的全肺候選產生器

核心假說：單次前向的影像–文字異常圖若與血管距離場、局部管狀性及 3D 跨切片一致性結合，能在不依賴結節像素標註預訓練的情況下，找出小於 6 mm 或貼血管的候選。原論文只展示 2D 醫療基準，肺 CT 全影像表現未知。

完整 CT → 肺區裁切→軸/冠/矢 2D RADIO 特徵→異常熱圖融合→vessel 距離＋管狀性校正→3D connected candidates→結節 GT 評估
最小實驗

固定 30–50 例有 GT 的 CT；每個 3D 體積以 1–2 mm 等向重採樣。比較原熱圖、血管 mask 抑制、血管邊界環帶加權三組；對照固定 FP/scan 下的敏感度，分報 <6 mm、血管黏連與非黏連。嚴禁用 GT box 產生推論提示。

難點與貢獻

RADIO 的 2D patch 可能比微小結節大，prompt 語義也可能不適用 CT。可把多視角一致性與「血管內低、血管邊界高」先驗做成可解釋的候選機制；若有效，最有價值的是降低人工標註需求的全肺召回。

啟發來源：RADIOlogy 論文、程式碼。

02 / CrossWeave × vessel graph

把血管樹當成 3D 參照系的稀疏對齊偵測器

核心假說：肺結節與周圍血管的相對幾何，比單一 CT patch 的紋理更能辨認黏連結節。借用 CrossWeave 的稀疏 patch–point 對齊，以 vessel mask 的中心線節點構圖，讓影像 patch 特徵對應到血管分叉、末端與管壁外側；再加結節候選節點做 GNN 聚合。

CT＋vessel mask→血管骨架與節點圖→3D patch/多平面特徵→稀疏 patch–node 對齊→GNN＋OT 聚合→結節中心＋mask
最小實驗

取結節中心周圍 64³ patch，建立至多 128 個血管骨架點；用 GT 中心作正 patch–node 鄰域，以離結節遠但血管形態相似的點作 hard negatives。先訓練二元候選分類，不做端到端全肺；與 CT-only 3D CNN、直接串接 vessel mask 比較，分報黏連組的 FROC。

難點與貢獻

血管分割錯誤會改變圖拓樸，GT 結節中心未必位於血管節點旁；用距離加權軟對齊與骨架擾動檢查魯棒性。潛在貢獻是以解剖幾何定義小病灶的對比學習單位，而非僅加一個 mask channel。

啟發來源：CrossWeave 論文、程式碼；相關舊基線：MICCAI 2026 肺結節圖表示（非本週新作）。

03 / Weight-Space Programming × Mamba segmentation

替結節分割器做可回退的微小權重修補

核心假說：若一個 3D 結節分割器反覆把血管誤併入結節，分析錯誤案例的中間通道與輸出頭後，或可對極少數通道做低秩或方向性權重編輯，專門修正「血管連通性」錯誤。MIT 示範的是遊戲策略與語言模型，這裡是全新的醫療影像假說。

CT＋vessel mask＋GT→凍結 3D U-Net/Mamba→收集貼血管失誤→通道與方向分析→稀疏權重編輯→全體測試集回歸檢查
最小實驗

先不用 LLM 自動改權重。以 10–20 例訓練集錯誤計算「血管假陽性 vs 真結節」特徵均值方向；僅修改輸出頭一個方向或一層 1×1×1 卷積，固定權重變化範數。和閾值調整、LoRA 微調比較，在獨立病人測試集量測血管 FP 體素、結節 Dice、<6 mm 召回。若手動方向有效，再讓 LLM 提議可審核的編輯候選。

難點與貢獻

局部收益可能破壞其他結節類型，資料洩漏會讓「修補」看似神奇。需預先鎖定測試集、記錄 diff 並保留回退。若奏效，可建立一種可稽核的錯誤特定權重修補，連結可解釋性與小樣本域適應。

啟發來源：MIT CSAIL 原文、完整日誌；Mamba 形態模組參考 MCDNet。

本週值得試玩的 GitHub / 5 picks

「值得試玩」指本週與新研究相連的開源入口，不代表每個程式庫都在本週首次建立。

RADIOlogy ↗

零訓練異常定位；同一輪 C-RADIOv4 特徵產生全域分數與 patch 異常圖，可直接改醫療 prompt 試 2D CT 切片。

門檻：中高；Python 3.12、PyTorch、首次需下載 RADIO 與 SigLIP2 權重，3D 融合需自行實作。

Weight-Space Programming logs ↗

逐實驗查看提示、程式、模型輸出和評估；最適合先重建權重 diff 與失敗案例，再思考醫影模型修補。

門檻：閱讀低、完整重跑高；大型權重與推論資源另需準備。

CrossWeave ↗

稀疏 2D patch–3D point 對齊，提供訓練與 checkpoint；可抽取對齊損失概念移植到 CT–血管圖。

門檻：高；Linux、NVIDIA CUDA 12.8、pixi、EGL；完整原資料快取很大。

logit-psv ↗

凍結模型的輸出擾動、篩選與投票；可先在肺結節候選分類 logits 上試簡化版穩健集成。

門檻：中；官方 repo 主要對應語言模型結果，醫影版本須自行改寫。

PhysicsNeMo-Mesh ↗

GPU 上批次處理 mesh 和帶邊界條件的模擬案例；適合血管表面網格與流場先驗原型。

門檻：高；GPU、網格/PDE 經驗；程式庫早於本週，這次是新論文。

下週可執行的 5 個研究實驗

01｜血管條件零樣本候選

RADIOlogy 軸/冠/矢切片熱圖融合；加入 vessel distance transform 前後比較 FROC@1/2/4 FP/scan，單列 <6 mm 組。

02｜血管黏連 hard negatives

從 vessel mask 骨架周圍採形態接近結節的假陽性 patch，訓練輕量候選判別頭；記錄黏連與非黏連差距。

03｜稀疏 CT–graph 對齊

在 64³ patch 上做 CrossWeave 式 patch–中心線節點對比損失；與單純 CT+mask concat 的相同 backbone 比較。

04｜微小權重修補

凍結既有分割器，只對輸出頭一個血管誤判方向作 bounded edit；與閾值調整及 LoRA 比較，設全測試集退化上限。

05｜頻帶角色分工

借 SpecSlot 概念，把 3D patch 的低頻形狀送全域路徑，高頻邊界留局部路徑；檢驗 <6 mm 邊界 Dice 及計算成本。

共同規格：病人層級切分；以完整 CT 推論而非 GT 裁切；另列每顆病灶召回、FROC、<6 mm 與 vessel-adjacent 子集、Dice/HD95、推論時間。若 GT 只提供點或框，須明確區分可評估偵測與可評估分割的樣本。
